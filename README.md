# FEM vs Projective Dynamics (2D)

左右 2 画面で、同じ弾性体（片持ち梁、床で跳ねるボール、左右に引き伸ばす長方形）を
**FEM**（左）と **Projective Dynamics**（右）で同時にシミュレーションして比較する Web アプリ。
材料は GUI の `material model` で **Corotational** と **Stable Neo-Hookean** を切り替えられる。

## 起動

公開版: <https://sasekazu.github.io/fem-pd/>

手元で動かす場合（three / lil-gui は CDN から読み込むのでネット接続が必要）:

```bash
npm start            # python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開く（ES Modules のため `file://` では動きません）。

## テスト

```bash
npm install          # テスト用の ml-matrix を取得（初回のみ）
npm test             # node --test（数値コアの単体テスト + 静的たわみの FEM/PD/梁理論の一致 + 疎 Cholesky の検証 + Neo-Hookean の検証）
```

## 比較の前提

- どちらも同じ材料エネルギー `μ‖F−R‖² + λ/2 (tr(RᵀF)−2)²`（corotational）。PD は ARAP 項（目標 `R`、重み `2μ`）と体積項
  （目標 `F − ((tr(RᵀF)−2)/2) R`、重み `2λ`）で、R を固定したときエネルギーが**厳密に一致**する（定常解は FEM と同じ）。
  `1/√det F` 型の面積制約は det→0 で爆発するため使わない。
- 要素が反転しても（E を小さくして根元が裏返る状況でも）FEM と PD は同程度に安定。
- 時間積分はどちらも陰的オイラー、減衰は同じ形式の速度減衰 `v ← v/(1+h·d)`。
- PD は反復回数を増やすと FEM の解に収束する（反復が少ないと柔らかく見える）。

## シーンと床接触

画面左上の `scene` で「Cantilever beam」と「Bouncing ball」を切り替える（ボールは円盤メッシュ、床は `y = floor height`）。

接触は**両手法で同じペナルティエネルギー** `Σ ½ k m_i max(0, floorY − y_i)²`（k は質量あたりの剛性 [1/s²]）。実現方法だけ手法ごとに変えている。

| | 方法 |
|---|---|
| FEM | 予測位置 `x + h(v+dv)` で接触力を評価して線形化し、接触頂点の剛性 `h² k m_i` を行列の対角に足す（活性集合が変われば最大 3 回まで再線形化） |
| PD | Liu, Bouaziz & Kavan (2016) の準ニュートン解釈。接触エネルギーを**目的関数と勾配にだけ**入れ、**定数行列は変えない**（再分解不要）。定数行列を初期逆ヘシアンとする **L-BFGS** と Armijo 直線探索で解く |

- 摩擦は未実装（垂直方向の跳ねのみ）。
- PD の L-BFGS 履歴は GUI の `PD L-BFGS history`（0 で L-BFGS なし＝勾配降下に近い PD + 直線探索）。
- 接触が硬い（k ≥ 1e7）と PD は反復が多く必要になる（Liu 2016 が述べるトレードオフ）。既定の k=1e6、PD 反復 20 では FEM とほぼ一致。
- 指標: 総エネルギー（運動 + 弾性 + 重力 + 接触）、最初の跳ね返り高さ（落下高さに対する %）。

### 実験結果（ボール r=0.5、E=1e6、1.0 m 落下、サブステップ 4）

| k | 最初の頂点高さ FEM | PD 10 反復 | PD 30 反復 | 最大めり込み |
|---|---|---|---|---|
| 1e5 | 1.065 | 1.069 | 1.069 | 6.1 cm |
| 1e6 | 0.964 | 0.972 | 0.972 | 8 mm |
| 1e7 | 0.947 | 0.929 | 0.955 | 0.8–1.5 mm |

どの設定でも総エネルギーは増えない（k=1e8 の PD 10 反復のみ過渡的に増加）。**サブステップ 1（1/60 s）では陰的オイラーの数値減衰で跳ねがほぼ消える**ため、ボールの既定はサブステップ 4。

参考文献（実装の根拠として読んだもの）:
[Liu, Bouaziz, Kavan 2016](https://arxiv.org/pdf/1604.07378)（§4.3 衝突）、
[Wang et al. 2020](https://arxiv.org/pdf/2008.01541)（Schur 補元による局所衝突処理：大規模向けなので不採用）。
Ly et al. 2020（摩擦つき PD）は未読。

## 引張試験（Stretch test）

正方形（1×1、16×16 分割）の左右の端列を、互いに逆向きに動かして引き伸ばす（片側 0.5 m/s、既定は 10 倍まで、重力 0）。
端の頂点は**強制変位**（`pinTarget`）で動かす。FEM は固定頂点の速度を指定して dv=0 とし、PD は固定頂点の寄与（`bFixed`）を毎ステップ再計算する（再分解は不要）。
画面下に「端の反力 – 伸び比」と「最小 det F – 伸び比」を FEM/PD で重ねて表示。GUI で load / hold / unload を切り替えられる。

### 結果（E=1e5、16×16、片側 0.5 m/s、サブステップ 2、PD 20 反復）

- **ν=0 では、どれだけ伸ばしても反転せず、反力は解析解 `E·H0·(s−1)` と一致**（s=5 で 400000、s=10 で 9.0e5。FEM・PD とも）。
- **ν>0 では、有限の伸び比 `s* = 1 + (1−ν)/ν` で要素が反転する。**
  corotational エネルギーの体積項は `tr(S)` に線形なので、一様な一軸引張の横方向の伸びは `s_y = 1 − ν/(1−ν)·(s−1)` になり、s* で 0 を通る（導出）。

| ν | 予想 s* | 実測の最初の反転（FEM / PD） | s=10 まで進めたとき反転要素数 | s=2 の反力（FEM / PD） |
|---|---|---|---|---|
| 0 | なし | なし | 0 | 100968 / 100968 |
| 0.2 | 5.00 | 5.12 / 5.12 | 336 / 336 | 108132 / 108136 |
| 0.3 | 3.33 | 3.31 / 3.31 | 424 / 424 | 120835 / 120850 |
| 0.4 | 2.50 | 2.33 / 2.33 | 436 / 456 | 152234 / 152304 |
| 0.45 | 2.22 | 1.84 / 1.84 | 434 / 480 | 192896 / 193098 |

- ν が小さい（0.2〜0.3）と予想とほぼ一致。ν が大きいと予想より早く反転する（端がつかまれているため端付近のせん断が先に効く）。
- 反転が始まる伸び比、反転前の反力は FEM と PD でほぼ同じ。反転後（s*超）も NaN や発散はなく、反力も近い値を保つ（ただし要素が大量に潰れており物理的には意味がない）。
- **反転した状態からも、除荷すれば元の形に完全に戻る**（ν=0.3、s=10 で 424/512 反転 → 除荷後 反転 0、最大偏差 0.000）。

**結論**: FEM と PD のどちらも「数値的には」非常に長く引き伸ばしても壊れない。ただし corotational 材料自体の限界として、ν に応じた伸び比（ν=0.3 で約 3.3 倍）で要素が反転する。それより大きな伸びを物理的に正しく扱うには、反転に強い材料モデル（Stable Neo-Hookean など）が必要。→ 次節。

## Stable Neo-Hookean

GUI の `material model` で選ぶ（切り替えるとシーンを作り直す）。2D の定式化（Smith, de Goes & Kim 2018 の 2D 版）:

```
Ψ(F) = μ/2 (‖F‖² − 2) − μ (J − 1) + λ'/2 (J − 1)²,   J = det F
P(F) = μ F + (λ'(J − 1) − μ) cof F
```

- F=I で Ψ=0、P=0（静止状態で安定）。J ≤ 0 でも Ψ は有限なので、反転しても元に戻る力が働く（`ln J` 型は J→0 で発散する）。
- **λ' = λ + μ**: `−μ(J−1)` を足すと静止状態の体積弾性が μ だけ下がる（展開すると線形弾性の λ が λ−μ になる）。λ' = λ + μ とすると静止状態のヘッシアンが線形弾性と一致し、小変形で corotational と同じ解になる（テストで確認）。3D の `μ' = 4μ/3, λ' = λ + 5μ/6` の 2D 版。
- ヘッシアンは `F = U diag(σ0,σ1) Vᵀ` の座標系で固有系が閉形式になる（twist `λ'(J−1)`、flip `2μ − λ'(J−1)`、スケーリングの 2×2 ブロック）。負の固有値を 0 にして Newton の行列を常に正定値にする（`snhHessian`）。

| | 方法 |
|---|---|
| FEM（左） | 増分ポテンシャル `Σ m‖x−y‖²/2h² + Ψ + 接触` を **Newton 法**で最小化。各反復で厳密な勾配と PSD 射影ヘッシアンを組み、CG で解く。接触もペナルティの勾配 + 対角ヘッシアンで同じ目的関数に入れる |
| PD（右） | Neo-Hookean は二次の射影の和にならないので local/global は使えない。**既存の定数 PD 行列を初期逆ヘシアンにした L-BFGS**で、同じ厳密な目的関数を最小化する（Liu et al. 2017 の準ニュートン解釈）。接触の有無に関わらず常に L-BFGS（履歴は最小 1） |

FEM と PD は**同じ目的関数**の最小化なので、収束すれば同じ解になる。`PD iterations` は Neo-Hookean では L-BFGS の反復回数。

### 結果（引張試験、E=1e5、16×16、片側 0.5 m/s、サブステップ 2、PD 20 反復、s=10 まで）

| ν | 反転要素数（FEM / PD） | 最小 det F | s=2 の反力（FEM / PD） | s=10 の反力（FEM / PD） |
|---|---|---|---|---|
| 0 | 0 / 0 | 1.000 | 87992 / 87992 | 519744 / 519745 |
| 0.2 | 0 / 0 | 1.000 | 79298 / 79298 | 439485 / 439486 |
| 0.3 | 0 / 0 | 0.727 | 76634 / 76634 | 410699 / 410690 |
| 0.4 | 0 / 0 | 0.228 | 75149 / 75149 | 388896 / 388890 |
| 0.45 | 0 / 0 | 0.126 | 75139 / 75139 | 381100 / 381108 |

- **どの ν でも一度も反転しない**（corotational は ν=0.3 で s≈3.3 から反転し、s=10 で 424/512 要素が反転）。
- FEM と PD は 5 桁以上一致する。
- 反力は線形でなくなる（ν=0 でも s=10 で corotational の 9.0e5 に対し 5.2e5）。Neo-Hookean 自体の性質。
- 折り畳んで反転させた初期状態からも、反転 0 に戻る（`test/neohookean.test.js`）。
- 計算コストは corotational より高い。梁（40×8）で FEM は Newton 約 3.4 回/ステップ、CG 約 200 反復/回で、corotational FEM の約 3〜4 倍。PD の L-BFGS は corotational PD と同程度（約 1〜1.5 ms）。

### 圧縮と解放（Stretch test の追加モード）

Stretch test のフォルダにある `test type` と `✂ release` で、反転しやすい状況を作れる。

- **Compress (grips together)**: グリップを内向きに動かして押し潰す（`min width ratio` まで）。
- **✂ release (snap back)**: グリップを離して自由にする（重力 0、減衰あり）。伸ばしたまま離すと縮みすぎる方向に大きくオーバーシュートする。`Reset` で再びつかむ。`unload` はグリップを一定速度で戻す従来の除荷で、解放とは別物。

実測（E=1e5、16×16、ν、サブステップ 4。数字は反転した要素の最大数 / 512、FEM と PD はほぼ同じ）:

| 条件 | corotational | Stable NH |
|---|---|---|
| 圧縮 → 0.5（ν=0.3） | 4 | 0 |
| 圧縮 → 0.3（ν=0.3） | 12 | 8 |
| 圧縮 → 0.15（ν=0.3） | 60〜72（最小 det F ≈ −0.9） | 16（最小 det F ≈ −0.13） |
| 圧縮 → 0.15（ν=0.45） | 88（最小 det F ≈ −0.7〜−0.8） | 12（最小 det F ≈ −0.2） |
| 3 倍から解放（ν=0.45） | 424〜436（最小 det F ≈ −6〜−11） | **0** |
| 6 倍から解放（ν=0.45） | 504〜512（最小 det F ≈ −44） | 64〜68（最小 det F ≈ −0.5） |
| 10 倍から解放（ν=0.3） | 508（最小 det F ≈ −32） | 216〜224（最小 det F ≈ −2） |

- **NH は反転を完全には防がない**（強い圧縮では要素が反転する）。違いは反転の**数と深さ**と、反転しても**元に戻れる**こと。
- 解放のあとはどちらも最終的に反転ゼロに戻る。ただし corotational は途中で全要素が裏返り、`min det F` が −数十〜−百以上まで落ちる。
- 自己接触がないため、強く解放すると物体が自分自身を通り抜けて回転して戻ることがある（実測の「最小の伸び比」が負になる）。元の形に戻っても、180° 回った姿勢になることがある。

## 疎 Cholesky の性能（Chrome、PD 10 反復/ステップ）

| 頂点数 | nnz(L) | 密だと | 初回分解 | PD 1 ステップ | FEM 1 ステップ（CG） |
|---|---|---|---|---|---|
| 369 | 3,740 | 64,980 | 20 ms | 1.9 ms | 9.4 ms（162 反復） |
| 1,377 | 25,720 | 925,480 | 36 ms | 7.5 ms | 52 ms（300 = 上限） |
| 5,313 | 189,936 | 13.9M | 82 ms | 37 ms | 237 ms（300 = 上限） |

CG は大きいメッシュで最大反復（既定 300）に達し未収束です。精度を揃えた比較をするなら CG 最大反復を増やしてください。

## 既知の制限

- 疎 Cholesky の並べ替えは RCM のみ（AMD に替えれば fill-in はさらに減る。`rcm()` を差し替えるだけ）。
- 線形三角形（CST）なので粗い厚み方向分割では曲げに対して硬くなる（せん断ロッキング）。
- Corotational 材料には要素反転への特別な対応はなし（反転に強いのは Stable Neo-Hookean を選んだとき）。
- Neo-Hookean は 2D 平面ひずみの Stable 型のみ（`ln J` 型の古典 Neo-Hookean は未実装）。PD の定数行列は `w = 2μ+2λ` のまま使うので、変形が大きいと L-BFGS の反復は corotational PD より多く要る。
- Neo-Hookean では `L-BFGS history`（PD）を 0 にしても履歴 1 で動く（plain PD は使えない）。
