# Corotational FEM vs Projective Dynamics (2D)

左右 2 画面で、同じ弾性体（片持ち梁、床で跳ねるボール、左右に引き伸ばす長方形）を
**Corotational FEM**（左）と **Projective Dynamics**（右）で同時にシミュレーションして比較する Web アプリ。

## 起動

公開版: <https://sasekazu.github.io/fem-pd/>

手元で動かす場合（three / lil-gui は CDN から読み込むのでネット接続が必要）:

```bash
npm start            # python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開く（ES Modules のため `file://` では動きません）。

## テスト

```bash
npm install          # テスト用の ml-matrix を取得（初回のみ）
npm test             # node --test（数値コアの単体テスト + 静的たわみの FEM/PD/梁理論の一致 + 疎 Cholesky の検証）
```

## 構成

| ファイル | 内容 |
|---|---|

| `src/sim/corotationalFEM.js` | 線形三角形 + 要素ごとの極分解、warped stiffness、陰的オイラー、Jacobi 前処理 CG |

| `src/sparse/cholesky.js` | 汎用の疎 Cholesky（RCM 並べ替え + 消去木 + up-looking 法、CSC）。メッシュ構造に依存しない |
| `src/sim/base.js` | 両ソルバ共通（状態・質量・固定点・外力・ひずみ計算）。`step(h) / reset() / setPinned() / addForce()` |

| `src/interaction.js` | マウスで掴んで引っ張る（三角形 + 重心座標で掴む点を表し、質量スケールのバネ・ダンパ力を `fext` に書く。DOM/three 非依存） |
| `src/render.js` | three.js 描画（`OrthographicCamera`、ひずみで頂点着色） |
| `src/main.js` | ループ、GUI（lil-gui）、左右ビューポート描画 |

## マウス操作

梁・ボールのシーンで、本体を**左ボタンでドラッグ**すると、掴んだ点にバネの力がかかる（左右どちらの画面で掴んでもよい）。

- 掴んだ点は「三角形 + 重心座標」で記憶し、**同じ材料点・同じ目標位置を FEM と PD の両方に**与える（同じ入力での比較になる）。
- 力は `a = k(目標 − p) − c·v_p`、頂点 j には `m_j w_j a`（質量スケール）。`fext` 経由の陽的な外力なので `k h² < 4` が安定条件で、`k` は `1/h²` で自動的に頭打ちになる。
- 重い物体（ボールなど）は局所質量に比例した力しか出ないので、シーンごとに剛性を変えている（梁 1500、ボール 8000。GUI の `Mouse` で調整可）。
- 引張試験のシーンは端の頂点を強制変位で動かしているため、マウスは無効。

## 比較の前提

- どちらも同じ材料エネルギー `μ‖F−R‖² + λ/2 (tr(RᵀF)−2)²`（corotational）。PD は ARAP 項（目標 `R`、重み `2μ`）と体積項
  （目標 `F − ((tr(RᵀF)−2)/2) R`、重み `2λ`）で、R を固定したときエネルギーが**厳密に一致**する（定常解は FEM と同じ）。
  `1/√det F` 型の面積制約は det→0 で爆発するため使わない。
- 要素が反転しても（E を小さくして根元が裏返る状況でも）FEM と PD は同程度に安定。
- 時間積分はどちらも陰的オイラー、減衰は同じ形式の速度減衰 `v ← v/(1+h·d)`。
- PD は反復回数を増やすと FEM の解に収束する（反復が少ないと柔らかく見える）。

## シーンと床接触

画面左上の `scene` で「Cantilever beam」と「Bouncing ball」を切り替える（ボールは円盤メッシュ、床は `y = floor height`）。

接触は**両手法で同じペナルティエネルギー** `Σ ½ k m_i max(0, floorY − y_i)²`（k は質量あたりの剛性 [1/s²]）。実現方法だけ手法ごとに変えている。

| | 方法 |
|---|---|
| FEM | 予測位置 `x + h(v+dv)` で接触力を評価して線形化し、接触頂点の剛性 `h² k m_i` を行列の対角に足す（活性集合が変われば最大 3 回まで再線形化） |
| PD | Liu, Bouaziz & Kavan (2016) の準ニュートン解釈。接触エネルギーを**目的関数と勾配にだけ**入れ、**定数行列は変えない**（再分解不要）。定数行列を初期逆ヘシアンとする **L-BFGS** と Armijo 直線探索で解く |

- 摩擦は未実装（垂直方向の跳ねのみ）。
- PD の L-BFGS 履歴は GUI の `PD L-BFGS history`（0 で L-BFGS なし＝勾配降下に近い PD + 直線探索）。
- 接触が硬い（k ≥ 1e7）と PD は反復が多く必要になる（Liu 2016 が述べるトレードオフ）。既定の k=1e6、PD 反復 20 では FEM とほぼ一致。
- 指標: 総エネルギー（運動 + 弾性 + 重力 + 接触）、最初の跳ね返り高さ（落下高さに対する %）。

### 実験結果（ボール r=0.5、E=1e6、1.0 m 落下、サブステップ 4）

| k | 最初の頂点高さ FEM | PD 10 反復 | PD 30 反復 | 最大めり込み |
|---|---|---|---|---|
| 1e5 | 1.065 | 1.069 | 1.069 | 6.1 cm |
| 1e6 | 0.964 | 0.972 | 0.972 | 8 mm |
| 1e7 | 0.947 | 0.929 | 0.955 | 0.8–1.5 mm |

どの設定でも総エネルギーは増えない（k=1e8 の PD 10 反復のみ過渡的に増加）。**サブステップ 1（1/60 s）では陰的オイラーの数値減衰で跳ねがほぼ消える**ため、ボールの既定はサブステップ 4。

参考文献（実装の根拠として読んだもの）:
[Liu, Bouaziz, Kavan 2016](https://arxiv.org/pdf/1604.07378)（§4.3 衝突）、
[Wang et al. 2020](https://arxiv.org/pdf/2008.01541)（Schur 補元による局所衝突処理：大規模向けなので不採用）。
Ly et al. 2020（摩擦つき PD）は未読。

## 引張試験（Stretch test）

正方形（1×1、16×16 分割）の左右の端列を、互いに逆向きに動かして引き伸ばす（片側 0.5 m/s、既定は 10 倍まで、重力 0）。
端の頂点は**強制変位**（`pinTarget`）で動かす。FEM は固定頂点の速度を指定して dv=0 とし、PD は固定頂点の寄与（`bFixed`）を毎ステップ再計算する（再分解は不要）。
画面下に「端の反力 – 伸び比」と「最小 det F – 伸び比」を FEM/PD で重ねて表示。GUI で load / hold / unload を切り替えられる。

### 結果（E=1e5、16×16、片側 0.5 m/s、サブステップ 2、PD 20 反復）

- **ν=0 では、どれだけ伸ばしても反転せず、反力は解析解 `E·H0·(s−1)` と一致**（s=5 で 400000、s=10 で 9.0e5。FEM・PD とも）。
- **ν>0 では、有限の伸び比 `s* = 1 + (1−ν)/ν` で要素が反転する。**
  corotational エネルギーの体積項は `tr(S)` に線形なので、一様な一軸引張の横方向の伸びは `s_y = 1 − ν/(1−ν)·(s−1)` になり、s* で 0 を通る（導出）。

| ν | 予想 s* | 実測の最初の反転（FEM / PD） | s=10 まで進めたとき反転要素数 | s=2 の反力（FEM / PD） |
|---|---|---|---|---|
| 0 | なし | なし | 0 | 100968 / 100968 |
| 0.2 | 5.00 | 5.12 / 5.12 | 336 / 336 | 108132 / 108136 |
| 0.3 | 3.33 | 3.31 / 3.31 | 424 / 424 | 120835 / 120850 |
| 0.4 | 2.50 | 2.33 / 2.33 | 436 / 456 | 152234 / 152304 |
| 0.45 | 2.22 | 1.84 / 1.84 | 434 / 480 | 192896 / 193098 |

- ν が小さい（0.2〜0.3）と予想とほぼ一致。ν が大きいと予想より早く反転する（端がつかまれているため端付近のせん断が先に効く）。
- 反転が始まる伸び比、反転前の反力は FEM と PD でほぼ同じ。反転後（s*超）も NaN や発散はなく、反力も近い値を保つ（ただし要素が大量に潰れており物理的には意味がない）。
- **反転した状態からも、除荷すれば元の形に完全に戻る**（ν=0.3、s=10 で 424/512 反転 → 除荷後 反転 0、最大偏差 0.000）。

**結論**: FEM と PD のどちらも「数値的には」非常に長く引き伸ばしても壊れない。ただし corotational 材料自体の限界として、ν に応じた伸び比（ν=0.3 で約 3.3 倍）で要素が反転する。それより大きな伸びを物理的に正しく扱うには、反転に強い材料モデル（Stable Neo-Hookean など）が必要。

## 疎 Cholesky の性能（Chrome、PD 10 反復/ステップ）

| 頂点数 | nnz(L) | 密だと | 初回分解 | PD 1 ステップ | FEM 1 ステップ（CG） |
|---|---|---|---|---|---|
| 369 | 3,740 | 64,980 | 20 ms | 1.9 ms | 9.4 ms（162 反復） |
| 1,377 | 25,720 | 925,480 | 36 ms | 7.5 ms | 52 ms（300 = 上限） |
| 5,313 | 189,936 | 13.9M | 82 ms | 37 ms | 237 ms（300 = 上限） |

CG は大きいメッシュで最大反復（既定 300）に達し未収束です。精度を揃えた比較をするなら CG 最大反復を増やしてください。

## 既知の制限

- 疎 Cholesky の並べ替えは RCM のみ（AMD に替えれば fill-in はさらに減る。`rcm()` を差し替えるだけ）。
- 線形三角形（CST）なので粗い厚み方向分割では曲げに対して硬くなる（せん断ロッキング）。
- 要素反転への特別な対応はなし。
